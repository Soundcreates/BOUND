DNS/TLS drift (separate harness, not a page button)

A page button cannot safely trigger this — see why below. Run it from a terminal instead:

cp .env.example .env   # from the repository root; set BOUND_DEMO_TOKEN / BOUND_DEMO_SPENDER to local test contracts
node --env-file=.env server/demo/hijack-server/run.mjs
# then at the prompt: type "hijack" to flip the backend, "normal" to restore

The mode switch is deliberately stdin-only, not an HTTP/page-triggerable endpoint — a same-origin attacker in a real hijack doesn't ask your page's permission before swapping the backend, so letting this page flip it would make the drill unrealistic. Run the watcher (see chat) alongside it to see BOUND's drift alert fire before any wallet interaction.
